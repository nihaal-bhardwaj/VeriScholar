# Sample papers

Placeholder directory for permissively licensed sample PDFs used in manual testing and demo scripts.

Rules:

- Only add papers you have the right to redistribute (e.g. CC-licensed preprints, public-domain documents, self-authored test papers).
- Do not commit copyrighted research papers.
- Generate synthetic PDFs programmatically for automated tests (see `backend/tests/`).

A generated demo script can produce a PDF on the fly; see `backend/app/services/pdf_parser.py` and the test suite for a reproducible example.
